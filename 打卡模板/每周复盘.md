# 每周复盘（模板）

> 用法：每周固定一个时间（比如周日晚上）填一次，5–10 分钟。目的是"根据上周实际情况，微调下周"。

```
第 ___ 周（__月__日 – __月__日）　所处阶段：□基础期 □进阶期 □专项期 □减量期

一、完成情况
- 计划练几次 / 实际练几次：___ / ___
- 本周总跑量（km）：___
- 最长一次（km）：___
- 有没有做力量训练（次）：___

二、身体
- 整体疲劳（1–10）：___
- 有没有反复出现的酸痛 / 不适：___
- 睡眠平均（h）：___　静息心率趋势：□下降 □稳定 □升高
- 静息心率连续升高 或 睡不好 或 没动力 → 下周主动减量 20–30%

三、感受
- 这周哪次跑得最舒服，为什么：
- 哪次很勉强，为什么：
- 打卡有没有断，断在哪、什么原因：

四、下周调整（只改一点点）
- 跑量：□持平 □+10%以内 □减量
- 要不要加 / 减一次强度课：
- 一个具体改进动作：
```

## 加量红线

- 周跑量每周增幅 **不超过约 10%**。
- 连续加 3 周，第 4 周**减量周**（降到约 70%）。
- 任何一周身体亮红灯，优先减量，不追进度。
