# 人人都能跑马拉松

一个帮**零基础跑者**从头训练、最终跑完**半程马拉松（21.0975 公里）**的项目。

## 现在的主体：打卡 App

`app/index.html` —— 一个手机网页 App，40 周训练计划 + 逐次打卡。

**打开地址**：<https://claude.ai/code/artifact/3c450151-f9a3-45f4-8f0f-5fc3e5d5a1f2>
（iPhone Safari 打开 → 添加到主屏幕，当 App 用。详见 `app/README.md`）

- 起点：能连续跑 10–20 分钟，每周练 3 次
- 目标比赛日：2027-06-24
- 每次跑完点「完成」，顶部看倒计时和总进度，进度云端同步

## 训练方法一句话

80% 的跑量用「能聊天」的轻松配速打有氧底子；每周加量不超过约 10%，每 4 周减量一次；
长距离最多练到 19 公里；节奏跑和比赛配速训练留到赛前几个月才加重。
方法参考盖洛威走跑结合、丹尼尔斯配速分区、汉森半马专项等，见 `参考资料/参考书目.md`。
