# 人人都能跑马拉松

> 副标题（暂定，可改）：**从零开始，半年到一年，安全跑完人生第一场半程马拉松**

## 这是什么

一本面向**完全零基础跑步新手**的训练手册。目标读者可能：

- 现在连续跑 1 公里都困难
- 久坐多年，或体重偏高
- 没有任何运动队 / 教练背景

我们要带这样的人，用 **6–12 个月**，通过**科学、循序渐进、以有氧耐力为地基**的训练，
安全无伤地跑完一场**半程马拉松（21.0975 公里）**。

## 核心主张

1. **慢就是快**：新手 80% 的跑量应该是"轻松到能聊天"的强度。
2. **系统 > 意志**：不靠咬牙硬撑，靠一套可执行的训练计划 + 打卡系统 + 习惯设计。
3. **每个动作都讲"为什么"**：不灌鸡汤，讲清楚身体是怎么变强的。
4. **无伤优先**：宁可慢一个月，不受一次伤。

## 项目怎么组织

| 目录 | 放什么 |
|---|---|
| `大纲.md` | 全书结构总览（**活文档，会一直改**） |
| `正文/` | 各章节草稿，按"部分"分文件夹 |
| `训练计划/` | 可打印的周计划表（24 周 / 48 周两版） |
| `打卡模板/` | 每日日志、每周复盘、每月体能测试模板 |
| `参考资料/` | 参考书目、术语表 |
| `素材/` | 图片、图表 |
| `更新日志.md` | 每次较大改动记一笔（方便回看项目怎么长起来的） |

## 怎么用这个仓库

- **作为作者**：改 `大纲.md` 定结构 → 在 `正文/` 里逐节写 → 用 `git commit` 存档 → 用 `更新日志.md` 记里程碑。
- **作为读者（未来）**：从 `正文/00-前言.md` 开始读，配合 `训练计划/` 和 `打卡模板/` 执行。
