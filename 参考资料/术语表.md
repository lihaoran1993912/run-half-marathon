# 术语表

> 正文第一次出现某个术语时，链接到这里。保持"一句话能懂"。

| 术语 | 一句话解释 |
|---|---|
| 半程马拉松 | 21.0975 公里，常简称"半马"。全程马拉松是 42.195 公里。 |
| 有氧运动 | 强度低到身体能靠氧气持续供能、可以边做边说话的运动。跑步训练的主体。 |
| 无氧运动 | 强度高到氧气来不及供能、只能坚持较短时间的运动，比如冲刺。 |
| 轻松跑（E） | 慢到能完整说话的配速，训练里占比最大。 |
| 长距离慢跑（LSD） | 每周一次、距离最长的一次跑，比轻松跑还慢一点，练耐力。 |
| 节奏跑 / 乳酸阈跑（T） | "舒服的辛苦"——能说短句、不能聊天的强度，练"撑得更久"的能力。 |
| 间歇跑（I） | 快跑一段 + 慢跑恢复，反复多组，练最大摄氧能力。新手后期才用。 |
| 快步跑（strides） | 每次 15–20 秒的轻快加速，跑完不喘，用来改善跑姿和脚感。 |
| 法特雷克（Fartlek） | 瑞典语"速度游戏"，跑中随性加速减速，把强度训练玩得不枯燥。 |
| RPE | 主观用力感觉，1（几乎没感觉）到 10（拼尽全力）。 |
| 配速 | 跑 1 公里花的时间，比如"6分30秒/公里"。 |
| 静息心率 | 早晨刚醒、没起床时测的心率，长期升高提示疲劳或生病。 |
| 最大心率 | 心脏能达到的最高跳动频率，粗估约 = 220 − 年龄（个体差异大）。 |
| MAF 180 | 马费通提出的低心率训练法，训练心率上限 ≈ 180 − 年龄。 |
| VDOT | 丹尼尔斯用一次比赛成绩换算出的"跑力值"，用来定各档训练配速。 |
| 周期化 | 把训练按阶段安排：先打基础，再加强度，赛前减量，赛后恢复。 |
| 渐进超负荷 | 训练量一点点加，身体适应了再加，从而持续变强。 |
| 10% 原则 | 每周跑量增幅大致不超过上周的 10%，降低受伤风险。 |
| 超量恢复 | 训练造成疲劳，休息后身体修复到比原来更强的水平。 |
| 减量周 | 每隔几周主动把跑量降下来的一周，让身体吸收前面的训练。 |
| 减量 / Taper | 比赛前 1–2 周大幅降低跑量、卸掉疲劳，让比赛日状态最好。 |
| 撞墙 | 长距离中后段突然极度疲惫、跑不动，多与糖原耗尽有关。 |
| 负分段（negative split） | 后半程比前半程跑得更快的配速策略。 |
| 交叉训练 | 用骑车、游泳等非跑步运动补充体能、分散冲击。 |
| 外胫夹 | 小腿胫骨内侧的疼痛，新手加量过猛时常见。 |
| 跑步膝 | 膝盖前侧 / 髌骨周围的疼痛，多与力量不足、跑量突增有关。 |
| 髂胫束综合征 | 膝盖外侧疼痛，常见于跑量增加过快或髋部力量弱。 |
| 足底筋膜炎 | 脚底靠近脚跟处的疼痛，早晨起床第一步最明显。 |
