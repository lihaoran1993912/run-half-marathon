# 哑铃力量 · 配合半马

手机打开：https://lihaoran1993912.github.io/run-half-marathon/strength/
（Safari 打开 → 分享 → 添加到主屏幕，之后离线也能用）

- 16 周 / 32 次，A、B 课轮换，放在不跑步的那天；按顺序做，忙了顺延（跟半马打卡一样）
- 器材：一对哑铃，每只每边 2 + 1.5 + 1.25 kg 三片 → 一只能拼出 0 / 2.5 / 3 / 4 / 5.5 / 6.5 / 7 / 9.5 kg（另加手柄）
- 每个动作按上次的记录自动建议重量（双重递进：次数做满 → 加一档）
- 4 个阶段：适应 → 建立 → 强化 → 维持；第 4/8/12 周减量；第 16 周赛前不练腿

开发：`npm test`（零依赖，node --test）· `npm run serve` 本地预览
发布：改了前端文件，`src/version.js` 和 `sw.js` 的版本号一起 +1
