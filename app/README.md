# app/ — 半马训练打卡（网页 App）

`index.html` 是这个打卡 App 的**全部源代码**（单文件，无依赖）。

## 已发布地址

<https://claude.ai/code/artifact/3c450151-f9a3-45f4-8f0f-5fc3e5d5a1f2>

在 iPhone 的 Safari 打开 → 分享按钮 → **添加到主屏幕**，就能像 App 一样用。

## 功能

- 40 周训练计划（零基础 → 半马 21.0975 km），每周 3 次跑步
- 每次跑步点「完成」打卡，自动记日期
- 顶部显示：距比赛还有多少天、总完成进度、当前是第几周
- 自动展开「本周」，往下滑有「回到本周」按钮
- ⚙ 设置里可改：训练开始日期、比赛日期；导出 / 导入备份；清空打卡
- 进度通过 claude.ai 的 `db` 能力**云端同步**（换设备也能看）；断网时暂存在本机，联网后自动合并

## 计划设计依据

- 起点假设：能连续跑 10–20 分钟，每周练 3 次
- 比赛日：2027-06-24（约 40 周训练窗口）
- 分期：适应期(1–4) → 基础期(5–16) → 进阶期(17–28) → 半马专项期(29–37) → 减量期(38–39) → 比赛周(40)
- 每周加量 ≤ 约 10%，每 4 周一个减量周
- 最长长距离 19 km（不必在训练中跑满 21）
- 强度：80% 轻松跑打有氧底子，节奏 / 比赛配速训练赛前才加重
- 参考方法见 `../参考资料/参考书目.md`（盖洛威走跑结合、丹尼尔斯配速分区、汉森半马专项等）

## 改这个文件

改完 `index.html` 后，重新发布到同一个地址即可（保持链接不变）。
